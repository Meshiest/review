# Bundled fonts

`SymbolsNerdFontMono-Regular.ttf` is "Symbols Nerd Font Mono" from the
Nerd Fonts release v3.5.1 (`NerdFontsSymbolsOnly.zip`,
https://github.com/ryanoasis/nerd-fonts/releases/tag/v3.5.1). It holds only
the Powerline, Font Awesome, Devicons, Codicons, Material and other icon
glyphs, one cell wide, so a terminal can draw prompt icons without an
installed Nerd Font.

License: MIT (`LICENSE-SymbolsNerdFontMono.txt`). The individual icon sets
carry their own licenses, listed in the Nerd Fonts repository.
